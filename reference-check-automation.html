Reference Check Automation

End-to-end automation of the reference check process — from candidate submission to recruiter notification. The recruiter triggers it once. Everything else runs itself.

Google Apps Script Google Sheets Google Forms Google Docs Google Drive SmartRecruiters Slack
The problem

Reference checks are nobody's favourite part of the hiring process. In most teams the workflow goes like this: recruiter emails the candidate asking for referee details, candidate replies eventually, recruiter emails each referee separately, chases the ones who don't respond, manually copies answers into a spreadsheet, formats a summary doc, and sends it to the hiring manager. Repeat for every hire.

It's not complicated work. It's just a lot of steps that all depend on someone remembering to do the next thing. Which means it's slow, inconsistent, and the first thing that gets dropped when a recruiter is juggling five open roles. A process that should take 24–48 hours regularly stretched to a week or more.

The data was also inconsistent — different recruiters asked different questions, stored responses differently, and there was no single source of truth. This project automates the whole thing.

How it works

The workflow runs in five sequential steps. Each one only fires if the previous one completed successfully — nothing runs twice, nothing skips ahead.

1
Prefill link generation
When a recruiter marks a candidate row in the masterlist, the script auto-generates a prefilled Google Form link scoped to that specific candidate. No manual URL construction or copy-pasting.
trigger: onEdit
2
Candidate submits referee details
The candidate fills in referee names, job titles, and contact details via the form. This replaces the email thread that would normally take two to three days of back-and-forth.
trigger: manual (candidate)
3
Referee forms go out + responses write back
On submission, the system generates a separate prefilled form for each referee and sends it automatically. When referees respond, their answers are verified and written back to the correct row in the masterlist in real time. Separate templates for peer and manager references.
trigger: onFormSubmit
4
PDF report generated
Once all referee responses are verified, a formatted PDF is built from a Google Docs template and saved to a structured Drive folder organised by Job ID and candidate name. Only fires after verification — no partial reports.
trigger: time-based or manual
5
Recruiter gets notified
A Slack DM goes to the requesting recruiter with a direct link to the completed report, candidate name, Job ID, and submission timestamp. Falls back to email if the Slack DM fails.
trigger: after PDF confirmed

What it doesn't do yet

There's no automated chasing built in. If a referee doesn't respond, someone still has to follow up manually. The next version will add time-based reminder emails to non-responding referees at set intervals, with an escalation to the recruiter if there's no response after a second nudge.

Want to use this? The repo includes modular scripts, a config file for your own IDs, and setup instructions. Real credentials have been stripped — you'll need to add your own Sheet ID, Form ID, Folder ID, and Slack bot token via Script Properties.
